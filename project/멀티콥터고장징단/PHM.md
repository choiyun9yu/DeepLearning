# PHM, Prognostics and Health Management

## 1. What is PHM?
- PHM 은 시스템이나 장비의 상태를 지속적으로 모니터링 하고, 고장을 예측하며, 유지보수 전략을 수립하는 기술 및 방법론이다.
- PHM 의 주요 목표는 시스템의 신뢰성을 높이고, 운영 비용을 줄이며, 시스템의 가동 시간을 극대화하는 것이다.

### 1-1. PHM 의 주요 구성 요소
#### 데이터 수집
- 센서, IoT 장치 등을 통해 실시간으로 데이터를 수집한다.
- 예를 들어, 온도, 진동, 압력, 전류와 같은 다양한 데이터를 모니터링 한다.

#### 데이터 분석
- 수집된 데이터를 분석하여 시스템의 현재 상태를 평가한다.
- 통계적 방법, 머신러닝 기법, 신호 처리 기술 등을 사용하여 데이터를 처리한다.

#### 고장 예측
- 데이터 분석 결과를 바탕으로 고장이 발생할 가능성을 예측한다.
- 예측 모델로는 회귀 분석, 의사결정 트리, 인공 신경망 등이 사용된다.

#### 건강 상태 평가
- 시스템의 건강 상태를 정량적으로 평가한다.
- 건강지표(Health Indicator)를 계산하여 시스템의 신뢰성을 판단한다.

#### 유지 보수 결정
- 예측된 고장 및 건강 상태에 따라 적절한 유지보수 시점을 결정한다.
- 예방 유지보수(Preventive Maintenance) 또는 예측 유지보수(Predictive Maintenance)를 통해 유지보수 활동을 계획한다.

### 1-2. PHM 의 응용 분야
- 항공우주: 항공기 엔진 및 시스템의 상태 모니터링과 고장 예측
- 산업 기계: 제조 장비의 성능 최적화 및 유지보수 관리
- 전력 시스템: 발전소 및 전력망의 상태 평가 및 유지보수
- 자동차: 차량의 성능 모니터링 및 예방 유지보수

### 1-3. PHM 의 장점
- 비용 절감: 고장을 미리 예측함으로써 비싼 수리 비용을 줄일 수 있다.
- 가용성 향상: 시스템의 가동 시간을 늘리고, 효율적인 유지보수를 통해 신뢰성을 높인다.
- 안전성 강화: 고장을 사전에 예측하여 안전사고를 예방할 수 있습니다.

## 2. PHM 에 사용되는 인공지능 알고리즘

### 2-1. 데이터 기반 알고리즘
-
#### 머신러닝 알고리즘
- Random Forest: 여러 개의 결정 트리를 결합한 앙상블 학습 기법으로, 고장 여부를 분류하고 예측하는 데 사용된다.
- SVM: 고장 상태와 정상 상태를 이준 분류하거나 이상 탐지에 사용된다.
- k-NN: 데이터 사이의 유사성을 바탕으로 가장 가까운 이웃 데이터를 찾아 시스템의 고장 여부를 예측한다.
- GBM: 여러 약한 예측 모델을 결합해 강력한 예측 성능을 발위하는 알고리즘으로, 고장 예지에 자주 사용된다.
- XGBoost/LightGBM: GBM 의 변형으로, 속도와 성능이 뛰어나 고장 예측에 많이 사용된다.
#### 딥러닝 알고리즘
- ANN(Artifical Neural Networks): 복잡한 데이터 관계를 학습할 수 있는 인공 신경망 알고리즘으로, 고장 예측과 진단에 많이 사용된다.
- CNN(Convolutional Neural Networks): 주로 이미지 기반 데이터 분석에 사용되만, 시계열 데이터의 패턴 탐지에도 적용 가능하여 진단 및 예측에 유용하다.
- RNN(Recurrent Neural Networks): 시계열 데이터를 분석하는데 유용하며, 고장 예측이나 상태 모니터링에 자주 사용된다.
  - LSTM (Long Short-Term Memory): RNN 의 일종으로, 장기적인 의존성을 학습할 수 있어 장기간의 상태 예측에 적합하다
  - GRU (Gated Recurrent Unit): LSTM 과 유사하지만 더 단순한 구조로, 시계열 데이터 분석에 적합하다.   
- Autoencoder: 비지도 학습 알고리즘으로, 정상 데이터를 학습하여 이상 상태 데이터를 탐지하는 데 유용하다.
- GANs(Generative Adversarial Networks): 고장 데이터를 생성하거나, 고장 가능성을 예측하는 데 사용할 수 있다.
#### 통계 및 확률 모델
- HMM (Hidden Markov Models): 시스템의 상태가 시간이 지남에 따라 변하는 과정을 확률 적으로 모델링하여, 고장 가능성을 예측하는 데 사용된다.
- GMM (Gaussian Mixture Models): 시스템의 여러 상태를 가우시안 분포로 모델링하여, 상태 분류 및 이상탐지에 사용된다.
- Kalman Filter: 시스템의 동적 상태를 추정하는 데 사용되며, 특정 상태의 변화를 추적하고 예측하는데 효과적이다.
- Particle Filter: 비선형 시스템에서 상태 추정 및 고장 예측을 위한 확률적 필터링 방법이다.
### 2-2. 물리기반 알고리즘
- 시스템의 물리적 동작 원리와 수학적 모델을 기반으로 고장 예측을 수행한다.
- 물리 기반 알고리즘은 시스템의 물리적, 역학적 특성을 분석하여 고장을 예측하는 데 유용하다.
#### 피로 균열 전파 모델 (Crack Propagation Models)
- 시스템에서 발생한 균열이 시간에 따라 어떻게 전파되는지 예측하여 수명을 예측한다.
  - Paris' Law: 피로 균열 전파의 가장 널리 사용되는 모델 중 하나로, 금속 피로 수명 예측에 자주 사용된다.
#### FEM (Finite Element Method)
- 시스템의 구조적 분석에 사용되며, 응력 해석이나 진동 분석을 통해 고장을 예측한다.
#### CFD (Computational Fluid Dynamics)
- 유체 흐름이 시스템 동작에 중요한 역할을 하는 시스템에서 사용된다.
- 예를 들어, 항공기 엔진이나 터빈 같은 시스템의 내구성이나 성능 저하를 예측하기 위해 사용된다.
- 유체의 압력, 온도, 속도 변화를분석하여 고장 가능성을 예측할 수 있다.
#### 열역학 모델 (Thermodynamic Models)
- 열을 많이 발생시키는 시스템(예: 전기 모터, 터빈 등)의 온도 변화를 분석하여 열로 인한 손상이나 저하를 예측한다.
- 온도 상승이 재료의 피로를 유발하거나 시스템의 고장을 일으킬 수 있으므로, 온도와 관련한 예측이 중요하다.
#### 신뢰성 모델 (Reliability Models)
- 시스템의 신뢰성을 확률적으로 예측하는 모델이다.
- 이 모델들은 주로 시스템의 주요 부품들에 대한 신뢰성 데이터를 이용해 고장 확률을 계산하고,
  시스템의 수명 및 유지 보수 주기를 예측하는데 사용된다.
- 대표적인 신뢰성 지표로는 MTBF(Mean Time Between Failures), MTTF(Mean Time to Failure) 등이 있다.
#### 균열 성장 모델 (Crack Growth Models)
- 시스템에서 발생한 균열이 시간에 따라 어떻게 전파되는지를 분석한다. 균열의 발생 시점 부터
  파국적 고장에 이르기까지의 경로를 예측하여 시스템의 잔여 수명을 추정한다.
- Paris' Law 와 같은 모델이 대표적이다.

### 2-3. 하이브리드 모델(Hybrid Models)
- 물리 기반 모델과 데이터 기반 모델을 결합한 하이브리드 접근법은 PHM 에서 점점 더 많이 사용되고 있다.
- 하이브리드 모델은 물리 기반 모델의 강력한 해석력과 데이터 기반 모델의 예측 성능을 결합하여 고장 예측의 정확성을 높이고,
  다양한 조건에서의 시스템 동작을 보다 정밀하게 예측할 수 있다.
#### 물리 기반 모델과 데이터 기반 모델의 결합
- 물리 기반 모델이 시스템의 기초적인 동작 원리를 설명하고, 데이터 기반 모델이 실시간 데이터를 바탕으로 예측 성능을 보완한다.
- 예를 들어, 기계 부품의 피로 수명을 물리적으로 계산한 후, 이를 실제 센서 데이터를 사용해서 실시간으로 조정하는 방식이다.
#### 모델 융합 (Model Fusion) 
- 서로 다른 모델들을 결합하여 시스템의 고장 예측 성능을 향상시키는 기법이다.
- 모델 융합은 여러 모델들의 예측 결과를 통합하여 더 정확한 예측을 가능하게 한다.

### 2-4. 고장 예측 및 이상 탐지를 위한 기타 알고리즘
- 이상 탐지와 고장 예측은 PHM 의 핵심 과제이다.
- 여기에서 사용되는 알고리즘들은 주로 시스템의 정상 상태와 비정상 상태를 구분하고,
  비정상 상태가 고장으로 이어질 가능성을 예측하는 데 중점을 둔다.
#### 이상 탐지 (Anomal Detection)
- 시스템이 정상적인 상태에서 벗어난 이상 상태를 탐지하는 데 사용된다.
####
- Isolation Forest: 데이터 포인트들을 분리하여 이상치를 탐지하는 비지도 학습 알고리즘이다.
- One-Class SVM: 정상 데이터를 학습한 후, 새로운 데이터가 정상 범위에 속하는지 아닌지를 판단하는 데 사용된다.
- DBSCAN(Density-Based Spatial Clustering of Applications with Noise): 밀도 기반 클러스터링 알고리즘으로,
  밀도가 낮은 데이터 포인트를 이상치로 탐지하는 데 적합하다.
#### 잔여 수명 예측 (RUL, Remaining Useful Life Prediction)
- 시스템이 언제 고장날지 예측하는 알고리즘이다. 센서 데이터를 기반으로 시스템의 현재 상태를 평가한 후,
  고장까지 남은 시간을 예측한다.
####
- Prognostics using Regression Models: 잔여 수명(RUL)을 예측하는 데 선형 회귀, 비선형 회귀, 서포트 벡터 회귀(SVR) 등이 사용된다.
- Prognostics using LSTM/GRU: 시계열 데이터를 다루는 RNN 기반의 모델들은 잔여 수명 예측에 매우 적합하다.
  이 알고리즘들은 시간에 따른 데이터의 의존성을 학습하여 시스템의 미래 상태를 예측할 수 있다. 특히 복잡한 시간 패턴을 다루는데 효과적이다.
- Survival Analysis (생존 분석): 의료 데이터 분석에서 주로 사용되었으나, PHM 에서도 잔여 수명을 예측하는 데 사용할 수 있다.
  시스템이 고장날 때까지의 시간을 예측하며, Kaplan-Meier 추정과 Cox 비례 위험 모델 같은 기법이 자주 사용된다.
- Bayesian Remiaing Useful Life Models: 베이지안 확률 모델을 사용하여 시스템의 잔여 수명을 예측한다.
  이 방법은 시스템의 불확실성을 잘 처리할 수 있어, 고장 예측의 신뢰 구간을 제공하는 데 유용하다.

### 2-5. 신호 처리 및 상태 모니터링 알고리즘
- PHM 에서 센서로 수집된 신호 데이터를 처리해 고장을 예측하는 것도 매우 중요한 작업이다.
- 신호 처리 알고리즘을 사용하여 진동, 온도, 소음, 전류 등 다양한 신호 데이터를 분서하고 고장 징후를 탐직한다.
#### 
- FFT (Fast Fourier TransForm): 시간 도메인 데이터를 주파수 도메인으로 변환하여 진동 신호에서 고장 징후를 분석하는데 사용된다.
  진동 분석에 자주 사용되며, 기계 부품의 상태 모니터링에 적합하다.
- Wavelet Transfrom: 신호를 시간-주파수 영역에서 분석하는 방법으로, 비정상적이거나 짧은 지속 시간의 신호를 탐지하는데 적합하다.
  이 방법은 진동 신호나 충격 신호 분석에 자주 사용된다.
- EMD (Empirical Mode Decomposition): 비선형, 비정상 신호를 분석하기 위한 방법이다.
  센서 데이터에서 고장의 징후를 분리할 수 있어, PHM 에서 고장 진단 및 예측에 자주 사용된다. 
- HHT (Hilbert-Huang Transform): EMD 와 HilvertTransform 을 결합한 방법으로, 비선형 신호 분석에 적합하다.
  기계의 진동이나 충격 신호에서 고장을 탐지하는 데 유용하다.
- Envelope Analysis: 고주파 신호를 분석하여 결함이나 고장 패턴을 감지하는 데 사용되는 방법이다.
  주로 회전 기계의 베어링 상태 모니터링에 사용된다.
